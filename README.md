# ИТ-проект: система управления уборкой помещений РТУ МИРЭА

Проект реализован на базе ТЗ из практической работы №2 и модели БД из практической работы №3.

## Что реализовано

- Авторизация по логину и паролю.
- Роли: администратор, ответственный за уборку, сотрудник клининговой службы.
- Управление заданиями: создание, назначение исполнителя, смена статусов.
- Чек-листы выполнения уборки.
- Учет использованных расходных материалов.
- Фотофиксация результата до/после уборки.
- Проверка качества ответственным сотрудником.
- Возврат задания на доработку с комментарием.
- Ежедневные, еженедельные и ежемесячные отчеты.
- Аналитика по статусам, сотрудникам, возвратам и расходникам.
- Журнал действий пользователей.

## Структура

```text
mirea-cleaning-system/
  app.py                         # backend + HTTP server
  cleaning.db                    # создается автоматически при первом запуске
  database/
    schema_sqlite.sql            # локальная runnable-схема
    schema_postgres.sql          # PostgreSQL-схема из ПР3
    seed.sql                     # тестовые данные
  static/
    index.html                   # интерфейс
    styles.css                   # стили
    app.js                       # frontend logic
    hero-cleaning.png            # локальный визуальный фон
  uploads/                       # загруженные фотоотчеты
```

## Запуск

```bash
python app.py
```

После запуска откройте:

```text
http://127.0.0.1:8000
```

## Соответствие ТЗ

| Требование | Реализация |
|---|---|
| Модуль управления заданиями | Раздел "Задания", API `/api/tasks`, таблица `tasks` |
| Модуль фотофиксации | Загрузка изображений в карточке задания, таблица `photo_reports` |
| Модуль проверки качества | Раздел "Проверка", таблицы `inspections`, `comments` |
| Модуль отчетности | Раздел "Отчеты", API `/api/reports`, CSV-экспорт |
| Модуль аналитики | Сводка, графики статусов, статистика сотрудников и материалов |
| Ролевая модель | Таблицы `roles`, `users`, разграничение действий в интерфейсе |
| История действий | Таблица `action_log`, раздел "Журнал" |
| Адаптивный интерфейс | CSS media queries для desktop/mobile |

## Примечание по базе данных

Для удобного локального запуска приложение использует SQLite без установки сторонних библиотек. Физическая PostgreSQL-схема из практической работы №3 сохранена в `database/schema_postgres.sql`; ее можно использовать для переноса проекта на PostgreSQL.
